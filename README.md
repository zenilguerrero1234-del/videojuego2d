##  1. Descripción del proyecto

El proyecto consiste en desarrollar un videojuego llamado **Caza de Espíritus 2D**, como parte de las actividades de la materia de Graficación. El juego está inspirado en la temática de Halloween y el Día de Muertos, por lo que cuenta con un escenario nocturno y diferentes personajes, como fantasmas, calaveras, calabazas, murciélagos y velas.

Para desarrollar el videojuego se utilizan HTML, CSS y JavaScript. También se emplea HTML5 Canvas para dibujar los objetos y mostrar sus movimientos dentro de la pantalla, mientras que Bootstrap ayuda a organizar los elementos de la interfaz.

Durante el juego, los personajes se desplazan por el escenario y es necesario hacer clic sobre ellos para atraparlos y conseguir puntos. Además, se incluyen animaciones, efectos de sonido, música de fondo y un sistema de puntuación que permite llevar un registro del avance.

---

##  2. Objetivo

El objetivo es crear un videojuego en 2D que permita poner en práctica los conocimientos adquiridos en la materia de Graficación mediante el uso de figuras, movimientos, animaciones e interacción con el usuario.

Entre las principales características del juego se encuentran las siguientes:

1. **Objetos en movimiento:** Mantener 25 objetos en pantalla que se desplazan en diferentes direcciones y realizan distintos movimientos.
2. **Colisiones y animaciones:** Incorporar rebotes en los bordes del escenario y efectos de partículas cuando se producen determinadas interacciones.
3. **Diseño temático:** Utilizar personajes relacionados con Halloween y el Día de Muertos, acompañados de un fondo de cementerio con lluvia y relámpagos.
4. **Interacción con el mouse:** Permitir que los personajes se atrapen mediante clics. Cuando un personaje es atrapado, aparece otro en una posición aleatoria para mantener la cantidad de objetos.
5. **Puntuación:** Mostrar los puntos obtenidos, las rachas de aciertos y la precisión de los clics.
6. **Menús y controles:** Incluir una pantalla de bienvenida, botones para pausar, reanudar y reiniciar la partida, así como un control para activar o silenciar el audio.

##  3. Justificación

La creación de este videojuego permite poner en práctica diferentes temas de la materia de Graficación y conocer cómo se pueden utilizar para desarrollar una aplicación interactiva.

Se utiliza HTML5 Canvas para dibujar los personajes y el escenario sin necesidad de agregar una gran cantidad de imágenes externas. Esto también permite modificar la posición de los objetos y crear sus animaciones mediante código JavaScript.

Los movimientos de los personajes se calculan mediante operaciones matemáticas, mientras que las colisiones permiten controlar los rebotes y algunas de las interacciones del juego. También se agregan efectos de iluminación, partículas y sonidos para hacer que la experiencia sea más entretenida.

Por otra parte, se utiliza Bootstrap para organizar los elementos de la interfaz y GitHub Pages para publicar el proyecto en internet. De esta manera, el videojuego puede abrirse desde un navegador sin necesidad de instalar un programa adicional.

##  4. Cómo jugar

### Pantalla de bienvenida

Al abrir el videojuego se muestra una pantalla inicial con el título, una breve explicación de la dinámica y el botón **🚀 Iniciar Cacería**. Al presionarlo, comienza la partida.

### Controles principales

- **Clic izquierdo:** Atrapar los espíritus que aparecen en pantalla para sumar puntos.
- **Rachas de aciertos:** Realizar varios aciertos en poco tiempo para aumentar el multiplicador de puntos.
- **Botón Pausar / Reanudar:** Detener temporalmente el juego o continuar la partida.
- **Botón Reiniciar:** Comenzar una nueva partida y restablecer los resultados.
- **Botón de audio:** Activar o silenciar la música y los efectos de sonido.

### Dinámica del juego

Durante la partida aparecen 25 objetos que se mueven por el escenario. Algunos rebotan en los bordes, mientras que otros realizan movimientos diferentes, como desplazamientos diagonales o circulares.

El objetivo es hacer clic sobre los personajes para atraparlos y obtener la mayor cantidad de puntos posible. Cada vez que se atrapa uno, aparece otro en una posición aleatoria para mantener la actividad del juego.

El escenario también incluye efectos visuales y un cursor con apariencia de mira que ayuda a mantener la temática del videojuego.
